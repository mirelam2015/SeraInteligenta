# Sera Inteligentă

**Capilna Mirela**, grupa 10LD541 · Proiect comun IoT și IoC

Aplicație desktop C# (WPF, .NET 8) pentru monitorizarea și controlul unei sere împărțite pe zone de cultură.
Proiectul este livrat în 5 etape (milestone-uri).

## Unde găsiți fiecare etapă

| Etapă | Folder | Conținut |
|---|---|---|
| **Milestone 1** – Fundația | [`Milestone1/`](Milestone1/) | Soluția (`SeraInteligenta.sln`), datele (`Date/`), testele și documentația (`Documentatie/`) |
| Milestone 2 – Simulare și automatizare | – | urmează |
| Milestone 3 – Comunicare IoT | – | urmează |
| Milestone 4 – Date și alerte | – | urmează |
| Milestone 5 – Avansat și final | – | urmează |
